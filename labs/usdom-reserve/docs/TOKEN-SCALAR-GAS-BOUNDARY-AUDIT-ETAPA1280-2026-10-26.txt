USDOM Solidity adversarial audit - stage 1280
Date: 2026-10-26
Scope: gas exhaustion at ERC-20 scalar read boundaries

Conclusion
==========

No new material production defect was found. USDOMProofReserve performs token scalar
reads through _staticcallWord with TOKEN_GAS_LIMIT = 500,000, copies at most one word,
requires exactly 32 return bytes, and maps call failure to UnsupportedToken. A token
that consumes all forwarded gas therefore cannot consume unbounded caller gas or
partially mutate reserve accounting.

Coverage added
==============

The hostile token scalar-return controller gained a selector-specific gas-exhaustion
mode. It loops until its STATICCALL allocation is exhausted. The existing scalar
boundary regression now exercises this fifth mode for:

- decimals() while constructing a reserve;
- balanceOf() before and after a deposit transfer; and
- balanceOf() before and after a withdrawal transfer.

The test proves each call fails closed, a failed deposit does not consume its ID or
create credit, and a failed payout does not mark the burn paid or release pending
debt. Restoring exact token behavior allows the intended operation to complete.
Production contracts and ABI were unchanged.
