USDⓄM RESERVE — DURABLE SAFE DEPLOYMENT PACKAGE (STAGE 414)
Date: 2026-10-22

Finding

The unsigned Safe deployment packages were written to predictable `/tmp`
paths with ordinary redirection. These bytes define the factory target,
initializers and predicted role addresses later signed during mainnet setup.
Public content still requires strong integrity: a linked, replaced or partially
written package must never become deployment authority.

Correction

- Primary and independent-secondary packages now live in the owner-only
  control-plane evidence directory.
- Both are streamed directly into the durable create-only writer.
- Every later recovery and evidence step uses the same durable primary path.
- Runbook regression rejects the old `/tmp` package names, requires the exact
  private path and requires atomic installation for both copies.

The existing byte-for-byte dual-RPC comparison, SHA-256 binding and rebuild
before each deployment remain in place.
