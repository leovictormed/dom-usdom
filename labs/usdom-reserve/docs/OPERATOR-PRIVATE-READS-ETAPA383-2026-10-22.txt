USDOM stage 383 — operator private reads
Date: 2026-10-22

Finding and correction
======================

Four production operator binaries still duplicated check-then-open logic for
owner-only snapshots, seals, credentials, authorization, proving keys,
observations and evidence. Their generic public-input readers remain bounded
captured-handle readers. Every owner-only branch now uses the shared retained-
parent, descriptor-relative private reader introduced in stage 382.

An explicit empty-payload variant was added only for TPM owner authorization,
where empty authorization is a valid deliberate configuration. It preserves
all directory, file, ownership, mode, link and no-follow checks.
