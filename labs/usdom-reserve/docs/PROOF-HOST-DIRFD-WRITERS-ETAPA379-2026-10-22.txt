USDOM stage 379 — retained-directory proof-host writers
Date: 2026-10-22

Finding
=======

The checkpoint, economic and RandomX proof hosts, plus the standalone RandomX
statement exporter, still published private artifacts through predictable
process-ID temporary pathnames followed by pathname-based rename.  This left a
weaker publication boundary than the retained owner-only directory authority
already used by the finalized-burn host.

Correction
==========

All four publishers now call dom_wallet_crypto::save_private_bytes.  The shared
writer retains and authenticates the owner-only parent directory, creates an
unpredictable mode-0600 temporary through that descriptor, writes and syncs the
exact bytes, atomically replaces the target through the same authority, syncs
the parent, and verifies the resulting object.  The checkpoint program adds
the dependency only to host-reference, so guest feature graphs and proof
program semantics are unchanged.

- cargo fmt and git diff whitespace checks pass
