Stage 1064 — independent fd-bound execution security audit
Date: 2026-10-23 (America/Sao_Paulo)
Status: concrete TOCTOU and environment gaps corrected

Scope
=====
Reviewed `tools/usdom-fd-exec.c`, both credential-bearing integrations and the
Stage-1063 fixture for syscall flags, descriptor lifetime, EVP SHA-256, path and
inode races, argv/environment construction, owner/mode policy, mount behavior,
dynamic-loader influence and error propagation.

Findings and corrections
========================
1. Material inode race. `openat2` plus execution of the same descriptor prevents
path substitution, but does not prevent a current-owner writer holding another
file descriptor from changing the inode after hashing and before the kernel
loads it. The launcher now copies bytes while hashing into a private
`memfd_create(MFD_CLOEXEC|MFD_ALLOW_SEALING)` image, authenticates the completed
copy, changes it to mode 0500, applies and verifies WRITE/GROW/SHRINK/SEAL seals,
and executes that immutable descriptor. Mutation of the source can now only
produce the expected authenticated image or a hash failure; it cannot change
bytes after authentication.

2. Caller PATH propagation. The prior environment copied caller-controlled
PATH into a credential-bearing child. The launcher now supplies a fixed system
PATH and accepts only an absolute HOME. The receiving-wallet entrypoint now
validates HOME as a direct current-user absolute directory, matching the
recovery drill.

3. Loader and privilege environment. Both integrations now remove every
inherited `LD_*` variable before compiling or starting the dynamically linked
launcher. The child already receives an allowlisted environment. The launcher
also rejects setuid/setgid sources and applies `PR_SET_NO_NEW_PRIVS` before
execution.

4. Robustness. Replaced the argc-sized stack VLA with checked heap allocation,
bounded authenticated images to 512 MiB, retries interrupted reads/writes,
closes the root/source descriptors before execution, and preserves exit 126 for
all launcher-boundary failures.

Preserved boundaries and residual trust
=======================================
- `openat2` still requires BENEATH, NO_SYMLINKS, NO_MAGICLINKS and NO_XDEV for
  the executable lookup; unsupported kernels fail closed.
- Source must be regular, single-link, root/current-user owned, executable,
  nonempty, bounded and not group/other writable.
- EVP SHA-256 is finalized at exactly 32 bytes; lowercase 64-hex input remains
  canonical. Digest equality is not secret-dependent.
- Root-owned kernel, dynamic loader, system shared libraries, compiler and
  `/etc/ld.so.preload` remain ceremony-host trust. User environment injection
  is removed, but this helper is not a defense against a compromised root or
  hostile mount namespace controlled by root.
