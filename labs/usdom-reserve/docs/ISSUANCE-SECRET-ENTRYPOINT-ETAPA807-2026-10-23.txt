ETAPA807 — ISSUANCE SECRET ENTRYPOINT
Date: 2026-10-23

Finding and correction
----------------------
The finalized-deposit issuance launcher disables tracing/core dumps and then
replaces itself with the token-bearing Node process, so it correctly creates no
temporary file requiring cleanup. It did, however, execute `node` through PATH.
A substituted process would inherit authorization to read the bearer token,
private registration and finalized-deposit witness.

The launcher now pins Node by absolute path, owner, link count, mode, trusted
directory, inode metadata and SHA-256, rechecks it immediately, and `exec`s only
that path. The issuance process retains secret file buffers in a tracked array
and zeros every buffer in `finally` on success or failure. Private-burn cleanup
remains covered by ETAPA785.

Validation
----------
New ingress/zeroization regressions plus private-burn cleanup pass 5/5 and reject
PATH Node execution. Both shell scripts pass `bash -n`; `git diff --check`
passes. No RPC, issuance, burn or funds operation ran.
