ETAPA 770 — proof-to-Ethereum unsigned submission handoff
Date: 2026-10-23
Scope: finalized-burn EVM artifact and checkpoint outer EVM artifact handoff into unsigned submission packages.

Finding
The finalized-burn writer already copied every authoritative input into private create-once files, built only from those snapshots, rechecked the workspace before publication, and verified/hash-bound the installed result. The analogous checkpoint writer did not: it built from workspace buffers and never read back or hashed the installed package. Although it re-read inputs before writing, its trust boundary and durable-output evidence were weaker and diverged from the finalized-burn path.

Correction
- Snapshot release, verifier, checkpoint statement, proof index and EVM seal into a mode-0700 temporary directory through writePrivateFileDurableNew.
- Read the snapshot through direct regular-file/private-mode checks and build only from those bytes.
- Preserve fail-closed ordering: an unconfigured release is rejected before any proof artifact access.
- Re-read all original project inputs before publication and reject any substitution.
- Install the JSON create-once, then read it back with bounds/private checks, compare exact bytes and report its SHA-256.
- Remove the private snapshot in finally on success or failure.
- No RPC, signature, broadcast, proof generation or conversion was executed.
