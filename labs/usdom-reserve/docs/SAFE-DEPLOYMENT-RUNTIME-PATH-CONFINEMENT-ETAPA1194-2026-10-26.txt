SAFE DEPLOYMENT RUNTIME PATH CONFINEMENT — STAGE 1194
Date: 2026-10-26

Finding
=======

Safe deployment needed user-local Node and Foundry directories during tool
discovery, then retained those writable directories in PATH for the complete
credential-bearing ceremony. Even pinned-tool predicates internally use basic
utilities such as stat, realpath, dirname, sha256sum and cut. A late executable
inserted ahead of `/usr/bin` could therefore subvert reattestation itself.

Correction
==========

Immediately after every ceremony-specific tool has an authenticated absolute
pathname, runtime PATH is reduced to `/usr/bin:/bin`. Node, Cast, jq, timeout,
cmp, setsid, flock, sleep, mktemp and chmod continue through their already
pinned absolute paths. A remaining basename use was removed with native shell
suffix expansion, avoiding another runtime lookup.
