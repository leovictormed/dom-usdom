Finding
=======

The mainnet preflight SDK already rejected proxy variables, custom CA paths,
disabled certificate verification and unsafe Node TLS options. The private
credential-hiding proxy reused catalog URL validation but did not invoke that
transport-environment gate itself. A direct or misconfigured launcher carrying
the expected marker could therefore weaken fetch TLS or route credential-bearing
requests through an environment proxy. An invalid system clock could likewise
undermine certificate expiry checks.

Correction
==========

Immediately after consuming its one-shot launcher marker and before reading the
runtime secret file, the proxy applies the shared secure HTTPS environment gate
and operational TLS wall-clock gate. Existing endpoint validation still requires
root HTTPS origins on canonical public DNS hostnames, catalog-pinned origin
commitments, distinct provider infrastructure and redirect:error on every fetch.
