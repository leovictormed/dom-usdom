Finding
=======

The private loopback proxy checked POST and an application/json media type, but
did not bind Host to its active loopback listener or explicitly reject duplicate
framing headers, Transfer-Encoding, Content-Encoding, Expect and Upgrade. Node's
parser rejects several malformed combinations, but the security boundary should
state and enforce the one HTTP representation accepted from Cast.

Correction
==========

Before capability routing or quota admission, the proxy now requires HTTP/1.1,
exact Host `127.0.0.1:<active port>`, exactly one Host, Content-Type and
Content-Length header, and exact `application/json`. It rejects transfer coding,
content coding, 100-continue and protocol upgrade. The server accepts at most 16
headers and retains one request per socket, short keepalive and bounded header
and request timeouts.
