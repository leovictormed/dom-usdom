Finding
=======

The mandatory imported-source provenance check parsed PROVENANCE.json and
LOCAL-CHANGES.json with native json.loads over pathname reads, then resolved and
reopened every named file. Duplicate keys, unbounded authority files, symlink
resolution, hardlinks and pathname replacement were not rejected. Assertions
also supplied incomplete schema/type validation and can be disabled by Python's
optimized mode.

Correction
==========

The gate now uses explicit fatal checks. Authority JSON and imported files are
opened component by component beneath the project directory with dir_fd and
O_NOFOLLOW. Each capture requires a regular, owner-controlled, non-group/world-
writable, single-link file within a fixed size cap, reads one descriptor snapshot, checks
stat stability, and verifies the pathname still names the captured inode.

Paths must be canonical relative POSIX paths without traversal, separators or
control characters. Strict UTF-8 JSON rejects duplicate keys. Exact schemas,
canonical lowercase SHA-256 digests, false readiness/pushed flags, change-set
inclusion and bounded nonempty reasons are enforced before file hashing.
