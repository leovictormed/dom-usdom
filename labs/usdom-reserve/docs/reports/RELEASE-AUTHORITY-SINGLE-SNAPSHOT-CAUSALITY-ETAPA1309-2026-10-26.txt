Finding
=======

The phase reconciler reopened proof-reserve.unconfigured.json at several phase
boundaries. In particular, deployment identity validation parsed one read while
the deployment package comparison hashed a later read. A concurrent file
replacement could therefore make the accepted configuration object and its
causal SHA-256 authority describe different generations.

Correction
==========

The reconciler now obtains a strict, bounded local JSON snapshot containing the
exact bytes, parsed value and SHA-256. Snapshots are cached by path for the whole
invocation. Identity, deployment, deposit and redemption checks all consume the
same proof-reserve snapshot. The finalized-burn verifier manifest uses the same
regular-file, owner-only, bounded snapshot boundary for its hash authority.
