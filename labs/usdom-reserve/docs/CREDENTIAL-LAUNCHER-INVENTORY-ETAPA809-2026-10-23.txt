Finding and correction
----------------------
The authenticated-checkpoint observer disables tracing/core dumps and then
executes a Node process that reads credential-bearing RPC source catalogs. It
still used `exec node` through PATH, allowing substitution immediately before
the process inherited credential access.

The observer now pins Node by absolute path, owner, link count, mode, trusted
directory, inode metadata and SHA-256, rechecks it immediately, and execs only
that identity. Together with the issuance launcher hardened in ETAPA807, these
are the two credential-bearing Node exec launchers. A global shell inventory
confirms no `exec node` via PATH remains. The only other process execs are a
non-secret proof planner Cargo handoff and two tiny signing-mode Bash wrappers,
outside bearer/password/token inheritance.
