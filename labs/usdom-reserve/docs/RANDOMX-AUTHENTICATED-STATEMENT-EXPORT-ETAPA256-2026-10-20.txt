USDOM stage 256 — authenticated canonical RandomX statement export
Date: 2026-10-20

Finding
=======

A canonically framed USDOMBL4 package does not prove by itself that its block
belongs to the authenticated DOM continuation. Accepting a package, header or
manually supplied network/height/seed tuple as measurement input would allow a
structurally valid but unrelated UDCRXST1 statement to be presented as release
evidence. A failed refresh could also leave an older statement on disk and make
the next preflight consume stale evidence.

Correction
==========

The feature-gated host binary `dom-usdom-export-randomx-statement` now accepts
no arguments and reads only these fixed canonical inputs:

* evidence/randomx-source/checkpoint-segment-transition.bin (UDCSTN02)
* evidence/randomx-source/checkpoint-segment-private-input.bin (UDCSPI01)
* evidence/randomx-source/checkpoint-segment-policy-input.bin (UDCSPOL1)
* evidence/randomx-source/checkpoint-segment-native-state-opening.bin (UDCSNS01)

It invokes `execute_checkpoint_segment_portable`, which validates the public
transition, committed packages and native/economic witnesses, immutable
Ethereum/native/privacy policy, prior state opening, block sequence, target,
accumulated work and terminal state. The terminal RandomX binding is therefore
derived from the exact executed segment rather than from operator-selected
fields. The tool does not execute RandomX, generate a receipt, mine, use a
wallet, access a network or accept a field override.

The exporter rejects symlinks and nonregular inputs, bounds every read, detects
device/inode/size replacement, invalidates both previous outputs before work,
and publishes the 384-byte statement and exact JSON origin report through
fsynced atomic renames. If either publication or any validation fails, no stale
statement/report pair remains usable.

Independent plan verification
=============================

`plan-randomx-measurement.mjs` now requires the saved export report and all four
source files. It opens them with O_NOFOLLOW, checks stable metadata, enforces the
exact report schema, recomputes all domain-separated source commitments, checks
the private-input commitment embedded in UDCSTN02, parses the terminal
USDOMBL4 package, reconstructs its 256-byte header from UDCRXST1, and recomputes
the BLAKE2b block identifier. The plan remains nonexecuting and fail-closed.
