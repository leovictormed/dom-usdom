========================
Production/release semantic authorities:

  executable and source/package equality (ETAPA700);
- native signing checker, native request preparer and aggregate readiness native validation:
  safely snapshotted/rechecked Cargo, bounded fatal/exact line output, empty stderr

  their outputs do not authorize release/signing/mainnet actions.

Finding and correction
======================
Candidate monitor snapshotReader accepted an operator-supplied absolute verifier path but did
not snapshot/recheck its identity. Its stdout used Node's tolerant string decoding, stderr was
ignored and JSON framing was not canonical, even though the result drives burn consistency and
emergency pause decisions.

Added snapshotExecutablePath with the same owner/mode/link/directory/hash/inode/metadata checks
as PATH-resolved tools. The monitor snapshots the absolute verifier on first use, invokes its
resolved path, rechecks it after every execution, rejects any stderr, parses bounded stdout bytes
with fatal UTF-8/duplicate-key protection and requires exact compact JSON plus one newline.
The fetched snapshot remains an exclusive 0600 file in a private temporary directory.

identity, mutation rejection, non-absolute rejection, resolved execution, post-child recheck,

The candidate monitor integration/EVM suite and all child processes were deliberately not run.

No heavy build, Cargo, Rust, Solidity, RISC0 proof, RPC, signing, transmission, deployment,
