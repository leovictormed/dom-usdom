ETAPA918 — RUST OPERATOR SECRET BOUNDARY INVENTORY
Date: 2026-10-23

Closed scope
- 14 production `crates/dom-node/src/bin/dom-usdom-*.rs` binaries.
- 19 production Rust modules in the checkpoint/economic/finalized-burn/RandomX proof hosts.
- Total: 33 production modules; no repository-wide scan and no build/proof execution.

Production classification
- 12/14 DOM operator binaries handle a password/credential, private witness,
  private input or recovery material; manifest-check and preactivation-anchor
  are public/configuration-only.
- Seven of those binaries consume plaintext wallet/recovery/TPM password files
  through the shared owner-only secret loader.
- 19 proof-host modules consume staged proof inputs/artifacts; their binary
  entrypoints accept no operator arguments beyond the executable name.
- 28 CLI modules parse argv paths/options; secret contents do not cross argv.
- Four modules read bounded proof/runtime environment configuration; no
  password, mnemonic, recovery seed, TPM authorization or bearer is sourced
  directly from environment in this scope.

Focused production-code signals (inline test modules excluded)
- argv parsers: 28 modules / 28 sites
- environment reads: 4 modules / 12 sites
- stdout status/evidence: 28 modules / 257 sites
- stderr diagnostics: 9 modules / 9 sites
- panic/expect/unwrap: 0 production sites
- temporary/staging APIs: 4 modules / 4 sites
- explicit Zeroizing/zeroize before this fix: 2 modules / 7 sites

Concrete finding and correction
The shared UTF-8 loader copied a Zeroizing byte buffer with `to_vec()`. That
created a second plaintext allocation; invalid UTF-8 dropped the copied bytes
without erasure, and a decoded secret rejected by length bounds was also
dropped without erasure. This boundary is used by seven in-scope credential
binaries.

The loader now transfers its sole Vec allocation into String with
`mem::take`, explicitly zeroizes bytes recovered from `FromUtf8Error`, and
zeroizes the decoded String before every post-decode bounds error. Successful
callers retain the existing move into WalletPassphrase/Zeroizing ownership.
A structural regression passes 1/1; rustfmt check and diff-check pass. Cargo
and proof builds were deliberately not run while the long proof is active.
