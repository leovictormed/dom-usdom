Scope

Finding and correction
- The focused boundary checker previously used pathname `stat`/`read_bytes`, had no source-size ceiling, did not validate executable framing or modes, and did not screen the explicit critical set for generated binaries or high-confidence secret forms. The broad source manifest closed some link attacks but did not make these publication-source properties explicit at this gate.
- Critical paths are now canonical relative POSIX paths and are opened component-by-component using O_NOFOLLOW beneath a stable root descriptor.

- Descriptor identity and terminal pathname identity are rechecked after a bounded read.
- ELF/archive/compressed magic and NUL-bearing content are rejected as generated/binary artifacts. Executable source must start with a shebang.
- Private-key PEM framing, credential-bearing URLs, literal private-key/mnemonic/seed/secret-key JSON values and secret file suffixes/names are rejected.
- Default MANIFEST hash binding remains unchanged and fail closed. Inventory-only mode performs all new checks without accepting a stale manifest.
