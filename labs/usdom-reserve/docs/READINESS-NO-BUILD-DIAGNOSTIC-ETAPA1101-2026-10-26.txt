USD0M readiness no-build diagnostic — Stage 1101 — 2026-10-26

Scope

The canonical readiness command rebuilds Solidity and, when configured, runs
the native Rust manifest checker. Those operations were prohibited while the
workspace build was coordinated elsewhere. Previously this made it impossible
to obtain a complete diagnostic report without starting Forge/Cargo.

Change

`check-mainnet-readiness.mjs` now accepts the explicit
`--diagnostic-no-build` suffix. It skips the Forge build and native Cargo
checker, retains all authority-byte snapshots, Git/Python repository checks,
pure readiness assessment and fail-closed blockers, and labels the result with
`usdom-readiness-diagnostic/v1`. It never treats a skipped compiled/native fact
as satisfied. The normal command and its canonical output are unchanged.
