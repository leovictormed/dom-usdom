ETAPA813 — CREDENTIAL FLOW ENVIRONMENT
Date: 2026-10-23

Finding and correction
----------------------
Six wallet, TPM, burn and deposit-witness flows pinned sensitive tools and
private cleanup paths but still inherited loader, Node, Rust/Cargo, proxy,
Foundry and Cast overrides. These could inject code, redirect credential-bearing
network traffic, change a Cargo build target/wrapper, or persist TLS secrets.

All six now sanitize those controls before any command resolution. They remove
loader/library hooks, Node injection/debug, TLS key logging, Rust wrappers and
flags, unsafe Cargo build/target overrides, all proxy variants, and every
`FOUNDRY_*`/`CAST_*` variable. `HOME`, `PATH` and `CARGO_HOME` remain because TPM
and foreground Cargo operations require them; secret values continue to enter
children only through owner-only files or validated explicit inputs.

Validation
----------
A structural inventory covers all six scripts. A hostile-environment harness
proves dangerous variables are absent while `HOME`/`CARGO_HOME` survive.
Environment plus cleanup suites pass 14/14; six scripts pass `bash -n`; `git
diff --check` passes. No Cargo, TPM, RPC, witness, burn or funds operation ran.
