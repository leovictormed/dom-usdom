SAFE DEPLOYMENT BOUNDED LEDGER CHANNELS — STAGE 1182
Date: 2026-10-26

Finding
=======

The Safe deployer's Ledger address query and signed-transaction creation were
time bounded, but their Cast stdout/stderr channels were not size, encoding or
success-channel bounded. A defective device or unexpected tool response could
grow command-substitution memory or the raw candidate file without limit, and
successful execution allowed unauthenticated diagnostic stderr.

Correction
==========

A shared Ledger-Cast runner now captures both channels in owner-only tmpfs,
checks fatal UTF-8 decoding, limits address output to 64 KiB, raw transaction
output to 2 MiB and stderr to 64 KiB, and requires empty stderr on success.
Failures disclose only a generic bounded status. The address is read through
the pinned private-file reader before exact comparison; the raw transaction
continues through the existing strict semantic validator.
