ETAPA940 — STAGED CONTENT SECRET SCANNER
Date: 2026-10-23

Finding
Path allowlists and sensitive-name filters cannot detect a secret stored under a
benign filename. Both release commit ceremonies inspected names/modes but did
not inspect the exact staged blob.

Correction
A bounded deterministic scanner now receives each `git show :path` blob before
commit. It fails closed on invalid UTF-8, blobs over 8 MiB, private-key PEM,
non-redacted secret JSON fields (password/passphrase/mnemonic/seed/private key,
bearer/RPC token/TPM owner auth), long signed raw transactions, and encoded
private witness/input fields. Patterns require schema keys or strong framing to
avoid treating public hashes, statements and redacted templates as secrets.
Both source and evidence ceremonies scan index bytes, avoiding working-tree
TOCTOU. No commit or push was executed.

Validation: adversarial/benign tests 2/2, Bash syntax and diff-check pass.
